# UFO Sgrognox

A game where you control a UFO and abduct cars and stuff while avoiding obstacles.

[👉 Play the game on itch.io](https://slashlab.itch.io/sgrognox)

## Installation from Source

1. Clone or download the repository.
2. Download, install, and open the [Unity Hub](https://unity.com/download).
3. In Unity Hub, go to **Installs** > **Install Editor** and select version **6.3 LTS** (`6000.3.0f1` or later).
4. Once the installation has finished, go to **Projects** > **Add** > **Add project from disk** and select the cloned/downloaded repository folder.
5. Open the project in Unity.
6. In the **Project** window, navigate to `Assets/Scenes` and double-click on `Game`.
7. To run the game, click the **Play** button at the top of the Unity Editor.
